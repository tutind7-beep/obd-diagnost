# OBD-Диагност

Приложение для диагностики автомобиля через OBD-II адаптер с советами ИИ.

## Скачать Android-приложение

Последняя версия (файл `.apk`):

**https://github.com/tutind7-beep/obd-diagnost/releases/latest/download/obd-diagnost.apk**

Если телефон старый и пишет «Приложение не установлено» из-за архитектуры —
скачайте версию для 32-битных телефонов:
[obd-diagnost-arm32.apk](https://github.com/tutind7-beep/obd-diagnost/releases/latest/download/obd-diagnost-arm32.apk)

Установка: скачайте файл на телефон, откройте его и разрешите установку из этого источника.
Все версии — в разделе [Releases](https://github.com/tutind7-beep/obd-diagnost/releases).

## Состав репозитория

| Папка | Что это |
|-------|---------|
| `macos/` | Веб-приложение на Flask: читает адаптер (BLE ELM327), показывает параметры, коды ошибок, даёт советы ИИ, диагностику по симптомам, VIN, уведомления в Telegram |
| `android/` | Мобильное приложение на Flutter: подключается к BLE- или Wi-Fi-адаптеру, читает параметры, коды ошибок, блоки управления, работает с облаком |
| `telegram/` | Telegram-бот (уведомления о критических ошибках) |

## Возможности

- **Поддержка адаптеров:** Bluetooth LE (сервисы FFF0, FFE0, Nordic UART), классический Bluetooth / USB-порт, Wi-Fi (ELM327).
- **32 параметра** в 7 группах: двигатель, температуры, топливо, воздух, электрика, лямбда-зонды, пробег.
- Живые параметры на главной: обороты, температура ОЖ, скорость, напряжение, коррекции топлива, дроссель, расход воздуха.
- **Чтение кодов ошибок** по блокам управления и **стирание ошибок** (режим 04).
- **Автоподбор протокола** связи (CAN, KWP, J1850) и **определение марки по VIN** из ЭБУ.
- Советы ИИ (DeepSeek): объяснение ошибки, вероятная запчасть, примерная стоимость, ссылки на магазины.
- Диагностика по симптомам без адаптера.
- Расшифровка VIN через сервис NHTSA.
- Голосовой ввод и озвучка ответа.
- Оценка состояния автомобиля (0–100).
- Уведомления в Telegram.

## Известные ограничения

Ниже — честный список ситуаций, когда приложение не даст результата,
и что с этим делать.

### Установка и телефон

- Нужен Android 7.0 и новее, а также поддержка Bluetooth LE (для BLE-адаптеров).
- Приложение подписано **своим ключом** (`CN=OBD Diagnost`). Ключ лежит вне
  репозитория; без него обновление поверх установленной версии не встанет.
- Версии 1.0.0 и 1.1.0 подписаны разными ключами: перед установкой 1.1.0
  удалите старую версию.
- На Android 11 и ниже для поиска BLE-адаптера должна быть включена
  геолокация — это требование системы, а не приложения.

### Адаптеры

- Поддержаны BLE-адаптеры с сервисами `FFF0/FFF1/FFF2`, `FFE0/FFE1`
  (HM-10) и Nordic UART (`6E400001`). Экзотические наборы UUID могут не найтись.
- Классический Bluetooth (SPP) и USB-адаптеры поддерживает только веб-версия на Mac.
- Один BLE-адаптер обслуживает один телефон: если он занят другим
  приложением (например, Car Scanner), подключение не пройдёт.
- Дешёвые клоны ELM327 v1.5 не умеют многокадровые ответы: VIN может не
  прочитаться, часть параметров будет пустой.

### Автомобиль

- Нужен включённый зажигание и машина с поддержкой OBD-II (обычно с 2001 года).
- Часть блоков управления не отвечает на запросы (зависит от марки и года):
  список блоков будет короче ожидаемого.
- Адаптер может ответить `NO DATA` на отдельные параметры — это нормально,
  машина их не отдаёт.

### Сеть и облако

- Аккаунт и история работают только при доступе в интернет.
- Бесплатный сервер Render засыпает: первый запрос может идти до 30 секунд.
  Приложение будит сервер само и ждёт до 120 секунд.
- **База облака пока временная**: при перезапуске сервиса аккаунты и история
  исчезают. Подробности и способы исправления — в `OBD-Cloud/README.md`.
- При подключении к Wi-Fi-адаптеру телефон уходит в сеть адаптера без
  интернета: диагностика работает, советы ИИ — нет, пока не вернётесь в
  обычную сеть.

## Запуск (macOS)

```bash
cd macos
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Варианты подключения:
python app.py --ble --ble-name "BROM S10"   # Bluetooth LE
python app.py --real --device /dev/tty.OBDII  # классический Bluetooth / USB
python app.py --wifi                         # Wi-Fi-адаптер (автопоиск)
python app.py --demo lean                    # демо-режим без машины
```

Откройте http://127.0.0.1:8765/

Адаптер можно переключить прямо в интерфейсе — панель «Подключение».

## Сборка Android

```bash
cd android
flutter pub get
flutter build apk --release
```

APK появится в `android/build/app/outputs/flutter-apk/app-release.apk`.

## Важно

- `token.txt` (токен Telegram-бота) и ключи API хранятся только локально и не попадают в репозиторий.
- Ключ DeepSeek приложение читает из переменной окружения `DEEPSEEK_API_KEY` или из файла `~/.jarvis/api_key`.
- Облачный бэкенд лежит в отдельном репозитории `obd-cloud`.
