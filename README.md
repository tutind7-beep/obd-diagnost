# OBD-Диагност

Приложение для диагностики автомобиля через OBD-II адаптер с советами ИИ.

## Состав репозитория

| Папка | Что это |
|-------|---------|
| `macos/` | Веб-приложение на Flask: читает адаптер (BLE ELM327), показывает параметры, коды ошибок, даёт советы ИИ, диагностику по симптомам, VIN, уведомления в Telegram |
| `android/` | Мобильное приложение на Flutter: подключается к BLE-адаптеру, читает параметры и коды ошибок |
| `telegram/` | Telegram-бот (уведомления о критических ошибках) |

## Возможности

- **Поддержка адаптеров:** Bluetooth LE, классический Bluetooth / USB-порт, Wi-Fi (ELM327).
- **32 параметра** в 7 группах: двигатель, температуры, топливо, воздух, электрика, лямбда-зонды, пробег.
- Живые параметры на главной: обороты, температура ОЖ, скорость, напряжение, коррекции топлива, дроссель, расход воздуха.
- **Чтение кодов ошибок** по блокам управления и **стирание ошибок** (режим 04).
- **Автоподбор протокола** связи (CAN, KWP, J1850) и **определение марки по VIN** из ЭБУ.
- Советы ИИ (DeepSeek): объяснение ошибки, вероятная запчасть, примерная стоимость, ссылки на магазины.
- Диагностика по симптомам без адаптера.
- Расшифровка VIN через сервис NHTSA.
- Голосовой ввод и озвучка ответа.
- Оценка состояния автомобиля (0–100).
- Уведомления в Telegram.

## Запуск (macOS)

```bash
cd macos
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Варианты подключения:
python app.py --ble --ble-name "BROM S10"   # Bluetooth LE
python app.py --real --device /dev/tty.OBDII  # классический Bluetooth / USB
python app.py --wifi                         # Wi-Fi-адаптер (автопоиск)
python app.py --demo lean                    # демо-режим без машины
```

Откройте http://127.0.0.1:8765/

Адаптер можно переключить прямо в интерфейсе — панель «Подключение».

## Сборка Android

```bash
cd android
flutter pub get
flutter build apk --release
```

APK появится в `android/build/app/outputs/flutter-apk/app-release.apk`.

## Важно

- `token.txt` (токен Telegram-бота) и ключи API хранятся только локально и не попадают в репозиторий.
- Ключ DeepSeek приложение читает из переменной окружения `DEEPSEEK_API_KEY` или из файла `~/.jarvis/api_key`.
- Облачный бэкенд лежит в отдельном репозитории `obd-cloud`.
